# 区域识别插件 roi_PaddleOCR-json

Umi-OCR 插件：**只提取框选区域内的文本**，支持多个命名区域、模板渲染与 TXT/CSV 导出。

典型用途：批量提取发票上的指定信息（如《发票号码》《增值税额》）。同一种发票的同一位置大致相似，
因此**只框选一次**，后续批量识别自动复用。

---

## 功能

- **只提取框选区域内的文本**：识别时把不在区域内的文字全部丢弃。
- **多个命名区域**：默认自动命名为"区域1、区域2..."，也可以输入自定义名称（如"发票号码"）覆盖。
- **只框选一次**：首次识别弹出框选窗口（QML），拖拽框选并命名区域后保存；之后批量识别不再弹窗。
- **区域预设**：把本次框选的一整组区域连同**名称 + 备注**存成预设，下次在设置里选中该预设即可直接识别
  （连框选窗口都不弹）；也可在框选窗口里随时「加载所选 / 更新所选 / 删除所选」。备注用来快速辨认
  "这是什么单据/场景"。
- **重新框选**：勾选「重新框选区域」后，本次识别只弹窗一次，从空白开始重新框选并覆盖旧区域。
- **取消即停止**：框选弹窗点「取消」= 本次识别停止区域提取，后续每张图片都会明确提示"已取消，未提取"。
- **模板渲染**：用 `{区域名}` 引用识别结果，如
  `发票号码是《{发票号码}》，税额是《{增值税额}》`
  → `发票号码是《12345678》，税额是《100.00》`。
- **TXT / CSV 导出**：CSV 每行一张图片，列为各区域名，UTF-8 BOM，Excel 直接打开不乱码。
- **两种识别模式**：`裁剪识别`（只识别区域，快，推荐）/ `整图识别后过滤`（整图识别后保留区域内文块）。
- **区域按百分比保存**：发票扫描件分辨率不同也能对齐同一位置。
- 关闭「启用区域识别」后，行为与普通 PaddleOCR 插件一致（整图识别）。

## 安装

### 1. 准备引擎文件

本插件负责“框选 + 区域控制 + 导出”，文字识别由 **PaddleOCR-json** 引擎完成（与 Umi 官方 Paddle 插件同一引擎）。

**方式 A（推荐）**：双击运行插件目录内的 `assemble.bat`，它会自动从官方 Paddle 插件目录
（`plugins\win7_x64_PaddleOCR-json`）复制引擎文件（exe / models / dll）到本插件目录。
**注意**：该脚本只会复制引擎文件，**不会**覆盖本插件的控制文件（`__init__.py` 等）。
若你的插件目录里出现了 `PPOCR_umi.py`，说明用了旧版脚本，请删除本插件文件夹后重新复制。

**方式 B（手动）**：

1. 到 [Umi-OCR_plugins 发布页](https://github.com/hiroi-sora/Umi-OCR_plugins/releases)
   下载 `win7_x64_PaddleOCR-json_*.7z` 并解压；
2. 把解压出的文件夹里的**引擎文件**（`PaddleOCR-json.exe`、`models` 文件夹、所有 `*.dll`）
   复制到本插件目录内。
   ⚠️ **不要**复制官方文件夹里的 `__init__.py`、`PPOCR_umi.py`、`PPOCR_config.py`、
   `i18n.csv` —— 它们是官方插件的控制文件，复制过来会覆盖本插件的同名文件，导致插件失效。
   复制完成后目录结构如下：

```
roi_PaddleOCR-json/
├─ __init__.py          ← 本插件的（不要被覆盖）
├─ roi_ocr.py
├─ PPOCR_api.py
├─ PaddleOCR-json.exe   ← 引擎（复制来的）
├─ models/              ← 模型库（复制来的）
├─ *.dll                ← 引擎依赖库（复制来的）
└─ ...
```

### 2. 放置插件

把整个 `roi_PaddleOCR-json` 文件夹复制（**复制，不要剪切/移动**）到 Umi-OCR 的插件目录：
`UmiOCR-data\plugins\`

启动 Umi-OCR，在 **全局设置 → 文字识别 → 当前接口** 下拉框中选择“区域识别”，点击「应用修改」。
批量OCR / 批量文档标签页的 OCR 设置组会变为「文字识别（区域识别）」。

## 使用

### 第一次使用（框选区域）

1. 打开 **批量OCR** 或 **批量文档** 标签页。
   - 批量文档页请将「OCR内容模式」设为 **整页强制OCR**（否则文本型 PDF 只识别内嵌图片，不会整页识别，
     也就不会弹框选窗口）。
2. 添加图片/发票 PDF，点击开始识别。此时会弹出框选窗口：
   - 鼠标左键**拖拽**框选一个区域，松开后输入框自动填入默认名"区域1"——直接回车即可，或输入自定义名称覆盖；
   - 重复框选更多区域（自动命名为"区域2、区域3..."）；
   - 点绿色「**完成**」按钮，窗口自动关闭，区域已保存。
3. 区域已保存到 `区域文件`（默认 `roi_PaddleOCR-json\regions.json`），**之后批量识别不再弹窗**。

### 保存与加载预设（推荐：换单据不用重框）

同一类单据只用框选一次，之后靠预设复用：

1. 在框选窗口里拖拽框选好所有区域并命名；
2. 点底部「**预设**」→「保存为预设」，填写**预设名称**（如"增值税发票"）和**备注**
   （如"号码在右上角，价税合计在右下角"），点「保存」。预设写入 `roi_PaddleOCR-json\presets.json`，
   与 `regions.json` 互不影响，可保存任意多个；
3. 点「完成」关闭窗口，本次识别正常进行。

下次使用：

- **方式 A（最省事）**：全局设置 →「区域预设」下拉框选择该预设（下拉里同时显示备注与区域数），
  点「应用修改」。之后识别直接用预设区域，**不再弹出框选窗口**。
  （新增/修改预设后，需要重新打开设置页或重启 Umi-OCR，下拉框才会刷新。）
- **方式 B**：框选窗口里点「预设」→ 选中一行 →「加载所选」→「完成」。

预设面板（框选窗口底部「预设」按钮）里的操作：

| 按钮 | 作用 |
| --- | --- |
| 加载所选 | 把所选预设的区域载入当前窗口（可再逐个调整后识别） |
| 保存为预设 | 把当前窗口的区域存成预设，填写名称 + 备注；**同名会覆盖** |
| 更新所选 | 用当前窗口的区域覆盖所选预设（名称、备注不变） |
| 删除所选 | 删除所选预设（连点两次确认，防误删） |

- 勾选「重新框选区域」时，本次识别改用新框选的区域，**不套用**已选预设。
- 预设只保存区域；导出模板、导出格式等其它设置仍在全局设置里维护。

### 重新框选区域

勾选全局设置里的「重新框选区域」后，**本次识别只弹窗一次**（从空白开始重新框选，覆盖旧区域），
之后的所有图片复用新框选的区域；引擎参数不变时不会再次弹窗。
如需再次重新框选：删除 `regions.json`，或修改任意引擎参数（如切换语言），或重启 Umi。

### 取消框选

框选弹窗点「取消」（或直接关窗口）后：

- 当前图片返回提示“已取消框选区域，本图片未提取”；
- **本次识别停止区域提取**：后续每张图片都会明确提示"已取消"，**不会**再弹窗，**不会**静默，
  也**不会**套用旧的区域文件；
- 约 60 秒后重新开始识别，才会再次弹窗；修改引擎参数可立即恢复。

### 批量提取

- 直接添加所有发票 → 开始识别。
- 每张图片只识别框选区域内的文本；结果按模板渲染并导出。

### 配置说明（全局设置）

| 配置 | 说明 |
| --- | --- |
| 启用区域识别 | 关闭后退化为普通整图识别 |
| 识别模式 | 裁剪识别（快，推荐）/ 整图识别后过滤 |
| 区域文件 | 框选区域保存位置（默认 `roi_PaddleOCR-json\regions.json`）；删除该文件可重新框选 |
| 重新框选区域 | 勾选后本次识别只弹一次框选窗口，从空白开始重新框选并覆盖已保存的区域；引擎参数不变时不会再次弹窗 |
| 区域预设 | 选中某个已保存的预设后，识别直接使用预设区域、不弹框选窗口；留空则使用「区域文件」中的区域。新增预设后需重开设置页刷新列表 |
| 导出模板 | 见下文“模板” |
| 导出格式 | 不导出 / TXT / CSV / TXT+CSV |
| 导出目录 | 导出文件保存目录（默认 `roi_PaddleOCR-json\导出结果`） |
| 引擎路径 | 留空自动查找（本插件目录或官方 Paddle 插件目录） |
| 文块保留规则 | 整图过滤模式下，文块“完全在区域内”或“中心点在区域内”才算保留 |
| 区域内文本连接符 | 区域内多个文字块的连接符（默认无；地址等多行可填空格） |

局部配置（各标签页可不同）：语言/模型库、纠正文本方向、限制图像边长。

### 模板

- 用 `{区域名}` 引用该区域识别出的文本。
- 示例：`发票号码是《{发票号码}》，税额是《{增值税额}》`
  → `发票号码是《NO12345678》，税额是《100.00》`
- 模板留空时，TXT 按 `区域名：文本` 分行输出；CSV 不受影响（列名=区域名）。
- `{{`、`}}` 等不会被当作占位符；不存在的区域名替换为空字符串。

### 导出

- **TXT**（`导出目录\字段提取.txt`）：每张图片一行模板渲染结果。
- **CSV**（`导出目录\字段提取.csv`）：表头 = `图片, 区域名1, 区域名2, ...`，每行一张图片。
- CSV 为 UTF-8 带 BOM，双击用 Excel 打开即可。

## 命令行测试（可选）

不打开 Umi 界面即可测试插件核心流程。用 Umi 自带的 Python 运行（在插件目录内）：

```bat
UmiOCR-data\runtime\python.exe cli_test.py --images 测试发票.png
```

常用参数：

```bat
:: 桩引擎快速验证（无需真实引擎文件）
python cli_test.py --stub --images 测试图.png

:: 不弹窗，命令行直接指定区域（百分比坐标），可多次 --region
python cli_test.py --region 12.5,8.3,37.5,15,发票号码 --region 12.5,33.3,31.25,40,增值税额 --images 图.png

:: 指定模板与导出格式
python cli_test.py --images 图.png --template "发票号码是《{发票号码}》" --export-mode both

:: 整图过滤模式 / 手动指定引擎
python cli_test.py --mode filter --exe D:\path\PaddleOCR-json.exe --images 图.png
```

注意：框选弹窗依赖 PySide2（仅 Umi 运行时自带），在普通 Python 环境执行命令行测试时
请用 `--region` 直接指定区域，避免弹窗报错。详细参数见 `cli_test.py --help`。

## 常见问题

- **全局设置里看不到本插件？**
  分两步确认：
  1. 插件是否加载成功：运行插件目录内的 `check_install.py` 诊断脚本（用 Umi 自带 Python）：
     ```bat
     UmiOCR-data\runtime\python.exe check_install.py
     ```
     脚本会检查目录结构、引擎文件，并模拟 Umi 加载插件，输出具体失败原因。
  2. 查看位置：加载成功后，在 **全局设置 → 文字识别 → 当前接口** 下拉框中选择「区域识别」，
     点击「应用修改」；批量OCR/批量文档标签页的 OCR 设置组会变为「文字识别（区域识别）」。

- **不弹框选窗口？**
  插件会在插件目录生成 `roi_debug.log` 调试日志，记录每一步的执行位置；把日志最后几行发给开发者即可定位。
  常见原因：
  1. 批量文档页的「OCR内容模式」不是「整页强制OCR」：文本型 PDF 默认只拷贝内嵌文本/识别内嵌图片，
     不会整页识别，也就不会弹框选窗口；
  2. 之前取消过框选：取消后本次识别停止提取，约 60 秒后（或修改引擎参数）重新识别才会再弹窗；
  3. 引擎启动超时（会显示明确错误）：引擎文件不完整，重跑 `assemble.bat`。

- **取消框选后，为什么后面每张图都提示"已取消"？**
  这是设计行为：取消 = 本次识别停止区域提取，每张图都明确提示，不会静默、也不会误用旧区域。
  想重新提取：等约 60 秒后重新开始识别（或修改任意引擎参数立即恢复）。

- **插件目录里出现了 PPOCR_umi.py / PPOCR_config.py？**
  说明插件文件夹被官方 Paddle 插件的文件覆盖了（旧版 assemble.bat 的 bug，或手动复制时把官方
  控制文件也复制了过来）。修复：删除 `plugins\roi_PaddleOCR-json` 文件夹 → 重新复制干净的插件
  文件夹 → 重新运行 `assemble.bat`（新版本只复制引擎文件）。

- **提示找不到引擎文件？**
  引擎文件（`PaddleOCR-json.exe`、`models`）还没放入插件目录，运行 `assemble.bat` 或手动复制。

- **换了一种发票，原来的区域对不上了怎么办？**
  在框选窗口里框好新区域 →「预设」→「保存为预设」（起个新名称）→「完成」；再到全局设置把
  「区域预设」切到新预设即可。之后在几种单据之间切换，只需改这个下拉框，不用重新框选。

## 文件结构

```
roi_PaddleOCR-json/
├─ __init__.py         插件入口（PluginInfo）
├─ roi_config.py       全局/局部配置项
├─ roi_ocr.py          接口类（引擎管理、区域识别、汇总、导出、取消/重选逻辑）
├─ roi_region.py       区域数据模型（regions.json 读写、坐标换算、文块过滤）
├─ roi_preset.py       区域预设（presets.json 读写：名称 + 备注 + 一组区域）
├─ roi_export.py       模板渲染与 TXT/CSV 导出
├─ region_window.py    框选窗口调度（QML，信号+事件模式，兼容 Umi 裁切版 PySide2）
├─ region_select.qml   框选窗口界面（QtQuick：拖拽框选、默认命名、预设面板、按钮、自动关闭）
├─ RegionBtn.qml       框选窗口按钮组件
├─ roi_debug.py        调试日志（roi_debug.log）
├─ PPOCR_api.py        PaddleOCR-json 通信库（官方插件复用，MIT）
├─ i18n.csv            界面翻译
├─ cli_test.py         独立命令行测试工具
├─ check_install.py    安装诊断脚本（排查插件未被 Umi 加载的问题）
├─ assemble.bat        引擎文件组装脚本
└─ README.md           本说明
```

引擎文件（`PaddleOCR-json.exe`、`models` 等）需自行组装，见上文“安装”。
